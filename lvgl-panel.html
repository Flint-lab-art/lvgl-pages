LVGL ／ 离屏渲染实验
v9.3.0 · gcc 11.4 · Ubuntu 22.04 · 无显示器

一台没有显示器的机器，
画出了这块屏。

这不是设计稿，也不是截图工具拼出来的效果图。这台 Linux 云主机上没有 X11、没有 SDL、没有窗口系统，LVGL 把 480×800 的界面直接渲染进一块内存缓冲区，再把字节导出成图片。

右边那张动图就是编译产物：C 代码、CMake、gcc，一路跑通后落盘的帧。

这套界面由什么组成

控件全部来自 LVGL 内置 Widget 体系，没有一张位图素材
  • lv_arc
  • lv_chart
  • lv_slider
  • lv_switch
  • lv_button
  • lv_label
  • LV_SYMBOL_*
  • flex 布局
  • 渐变 + 圆角
  • 阴影

界面的每一层都在 C 里写出来：卡片是带圆角与渐变的对象，温度环是 lv_arc，曲线是 lv_chart 的 12 个数据点，状态栏图标用的是内置符号字体，不需要额外图片资源。

运行时堆峰值 25.4 KB 是 lv_mem_monitor() 实测值；1.5 MB 的帧缓冲不属于 LVGL 内存池，它是一块独立的外部缓冲区——在真机上，这块正好对应屏幕的显示缓存。

main.c · 离屏渲染的关键三行
/* 没有窗口，只创建一块屏幕 */
lv_display_t * disp = lv_display_create(480, 800);
lv_display_set_color_format(disp, LV_COLOR_FORMAT_ARGB8888);
lv_display_set_buffers(disp, render_buf, NULL,
        sizeof(render_buf), LV_DISPLAY_RENDER_MODE_FULL);

/* flush 回调里把像素拷走，而不是刷到屏幕 */

GitHub Actions 怎么把它变成网站

push 一次，截图重新生成，页面自动发布
  • 1

    编译 demo

    runner 上装 gcc + cmake，浅克隆 LVGL v9.3.0 源码，链接静态库。

  • 2

    跑一次渲染

    程序自己画、自己导帧，产出 frame.raw，再用 Python 转成 PNG / GIF。

  • 3

    部署 Pages

    页面上传为 artifact，交给 deploy-pages 发布。整个流程不需要图形环境。

为什么这一步能成立：离屏渲染把「显示输出」变成一次函数回调。CI 里没有显示器，回调就把像素交给内存；真机上换成 SPI / RGB 屏的驱动，同一份界面代码不用改。
.github/workflows/pages.yml
on:
  push:
    branches: [main]
permissions:
  pages: write
  id-token: write

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: |
          git clone --depth 1 --branch v9.3.0 \
            https://github.com/lvgl/lvgl.git third_party/lvgl
          cmake -S demo -B build -DLVGL_DIR=third_party/lvgl
          cmake --build build -j
          ./build/render
          python3 scripts/raw2png.py
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site/
      - uses: actions/deploy-pages@v4
页面与截图均由本仓库构建产物生成 · 数据取自实际编译运行
